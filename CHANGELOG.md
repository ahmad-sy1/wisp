# Changelog

## Unreleased

- *Add integration* is a window now (board 10.3.1): search, categories, what each service does and how it connects, all from the keyboard if you like
- A switched-off Departure or GitHub tab stays quiet on the closed notch
- A shared design system (board 0.2): one set of colours, corners and buttons across the app, with hover and pressed states, and red text for *Disconnect*; Mail's filter is a segmented control
- wisp has its own app icon and menu bar icon (board 0.1); the menu bar icon is a template, so macOS colours it
- `wisp-hook` exits cleanly when wisp hangs up during a long event, and integration tests run the real helper: never blocking Claude Code, what it passes on, and never approving without a clear answer
- Builds go to `build.noindex`, so Spotlight only finds the installed wisp and not every build copy
- Closed notch: a finished focus session no longer takes the panel away from a permission request, a second flash gets its full time and a pass can't wash out a failure, the audio tap only runs while the music wings really show, and a status keeps its width while its digits change
- Every status on the closed notch is a word or a number now, so the notch stays narrow: *3/4* instead of *3/4 checks*; the tabs keep the details
- `/review-pr`: a Claude Code skill that reviews a pull request against wisp's own rules and proves each finding
- All Swift code is formatted with `swift-format`, and CI checks it on every pull request
- CI runs on every pull request with the same Xcode as development, and skips the build for documentation alone
- Departure assistant: when to leave for an event or to go home, from your calendar, by public transport, car or bike. Line numbers and tracks from NS and OVapi, traffic and *now or later* from Apple Maps, rain from Buienradar. A Departure tab (board 12), a countdown on the closed notch (board 11) and Settings → Departure (board 14), which now also holds the ride to your shift
- With every tab on, the tab bar's extras give way so the tabs never shift
- CI & PR radar: a GitHub tab with your pull requests and their checks, requested reviews and the contribution graph (board 13); the closed notch shows a run going, a failure or a review request, with a short tick or flash once per event (board 11, with a review request kept to one word so the notch stays narrow); Settings → GitHub for the account, repositories and notifications (board 15)
- Settings → Notch: choose what Home shows, as chips under the Home tab; what's left takes the room of what is off (#24)
- Claude Code settings and a hook for this repository that keep AI attribution out of commits and pull requests
- Settings → Focus: add your own rules (app, optional project → task), marked *Set by you* next to the *Learned* ones (#27)
- Settings → Music: the mini spectrum on or off, a battery saver for the spectrum, and which players show: Spotify, Apple Music, the browser (#26)
- Open the notch from the keyboard with ⌥Space, changeable in Settings → General (#25); opened that way it stays until you press the keys again, press Esc or click elsewhere, and ← → walk through the tabs
- Closing the notch hands typing back to the app you were in, and Esc can't close the notch window itself
- The notch no longer stays open by accident: when something reopens it while it is open, or when it grew under a mouse that stood still
- A focus session ends on time after the Mac has slept; its duration can't change in Settings while it runs
- The closed notch follows the lid: wings come back when the notch screen does, and empty music wings go after 3 s; a paused player can't keep them for longer than the minute
- Settings → Notch: switch tabs on or off and drag them into your own order; the tab bar follows (board 10.1, #24)
- Settings is a window with a sidebar: General, Notch (each tab's options), Integrations, Calendar & weather, Music and Focus (boards 10.1–10.6, #28); the departure card says how you travel (*22 min fietsen*)
- New mail peeks out of the notch with *Open / Delete / Later* (Delete moves it to the Gmail trash), and the closed notch shows the unread count; both can be switched off (board 8)
- System tab: battery, AirPods, CPU with the busiest app, storage, and the Wi-Fi name (with Location access from Settings) (board 7)
- Notes tab: quick notes stored on this Mac, click to edit, right-click to copy or delete (board 6)
- Disabled buttons are dimmed
- Clipboard tab: the last 20 copied texts with search and *Copy*, stored only on this Mac, never passwords; can be switched off in Settings (board 5)
- Focus timer tab: 25 / 50 / 90 minutes, a ring that keeps counting in the closed notch, the task from the calendar or the app in front (learns from corrections), today's sessions, *Do not disturb* through Shortcuts and *Start music* (board 4)
- English interface with Dutch as the first translation (String Catalogs), a language choice in Settings, and a CI check for missing translations (#12)
- Debug builds: `-settingsPage <page>` opens Settings on a page, and with `-snapshot` draws that window
- Debug builds: `-snapshot <file.png>` draws the open panel to a PNG, also with the screen locked
- Agenda: once nothing is left today, the timeline shows tomorrow's first two events under *Morgen*
- Agenda: the event that is on now gets its own card with *NU*, the time left and a progress bar (board 3.1)
- Debug builds: `-agendaTime 21:30` shows the Agenda tab at another time of today
- Agenda & weather tab: today's timeline from the macOS Calendar app with a *nu* line and a countdown, the weather from Open-Meteo, and when to leave for your next shift (board 3); Settings → Agenda & weer for calendars, shifts, the ride and the place
- Music: a live spectrum of what plays (24 bands, bass/mid/treble mix, loudness), the output quality, a one-time permission card, and states for paused and nothing playing; a real mini spectrum on the closed notch, which stays greyed for a minute after a pause (boards 9.1–9.6)
- The playing app above the song title, and *Open Spotify* when nothing plays
- Settings → Muziek: a switch for the live spectrum
- Glass music controls with hover and press feedback (#9)
- The hooks installer only touches wisp's own entries (#10)
- Music tab: artwork, progress, controls, output device and volume; artwork and an equalizer on the closed notch while music plays; the music tile on Home (#7)
- Local builds are signed with a Developer ID, so macOS remembers Keychain access across updates (#7)
- Mail tab with Gmail: read-only inbox over IMAP with push, *Alles / Ongelezen*, open in Gmail, unread badge (#6)
- Opening wisp again (Spotlight, Finder) opens Settings (#5)
- Sessions in an IDE that was started from the Claude desktop app now show up (#5)
- Claude Code: live sessions on Home, approvals from the notch, hooks installer with backup and confirmation (#4)
- Build check on every pull request; `install.sh` and a signed, notarized `release.sh` (#3)
- The notch panel: 600 pt, tab bar, fixed content area, Settings window with accent colour, close delay and open at login (#2)
